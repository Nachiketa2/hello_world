# Tic-Tac-Toe

A polished terminal Tic-Tac-Toe game written in C++. Play against an unbeatable computer opponent with colored results and replay support.

## Build and run

```sh
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o tictactoe
./tictactoe
```

Choose a square by entering its number. The computer plays as `O` and you play as `X`.
